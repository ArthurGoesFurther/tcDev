# TakeCareDev

[English](README.md) · **Русский** · [中文](README.zh-CN.md)

Пиксельное лицо, которое напоминает делать гимнастику для глаз и вставать со стула. Живёт в трее,
работает на Windows, macOS и Linux.

![icon](build/icon.png)

**Скачать:** [последний релиз](https://github.com/ArthurGoesFurther/tcDev/releases/latest)

| Система                      | Файл                                                                              |
| ---------------------------- | --------------------------------------------------------------------------------- |
| Windows                      | `TakeCareDev-0.1.0-win-portable.exe`                                              |
| macOS (Apple Silicon, M1–M4) | `TakeCareDev-0.1.0-mac-arm64.zip`                                                 |
| Linux                        | `TakeCareDev-0.1.0-linux-amd64.deb` или `TakeCareDev-0.1.0-linux-x86_64.AppImage` |

## Что умеет

- **Гимнастика для глаз.** Каждые N минут (по умолчанию 20, правило 20-20-20) рядом с курсором
  появляется пиксельное лицо и N секунд (по умолчанию 10) показывает упражнение: влево-вправо,
  вверх-вниз, круги, диагонали, восьмёрка, моргание, зажмуриться, вдаль, близко-далеко, отдых с
  закрытыми глазами. Просто следишь за его зрачками. Окно прозрачное, пропускает клики и не
  забирает фокус — печатать оно не мешает.
- **Встать и походить.** Каждые N минут (по умолчанию 50) — перерыв на N минут (по умолчанию 5):
  карточка с таймером, подсказкой (приседания, лестница, растяжка, вода), «Отложить» и
  «Пропустить».
- **Строгий режим.** Перерыв закрывает все мониторы и прячет кнопки. Экстренный выход — меню в
  трее.
- **Честный таймер.** По умолчанию таймер перерыва идёт, только пока ты не трогаешь мышь и
  клавиатуру — отсидеться перед экраном перерыва не выйдет.
- **Естественные перерывы.** Если тебя не было дольше N минут (или ноутбук спал), отсчёт
  начинается заново, а не дёргает сразу, как только сел.
- Уведомление за N секунд до перерыва.
- Пауза на 30 мин / 1 ч / 2 ч / до возобновления, статистика за день, автозапуск.
- Можно выбрать упражнения, их порядок, размер лица, угол экрана вместо курсора, подсказку и звук.
- Интерфейс на русском и английском.

Все интервалы и длительности настраиваются: трей → «Настройки…» или повторный запуск приложения.

### Первый запуск

- **Windows:** сборка без подписи, SmartScreen предупредит — «Подробнее» → «Выполнить в любом
  случае».
- **macOS:** ad-hoc подпись без нотаризации. Распакуй, перенеси `TakeCareDev.app` в «Программы» и
  выполни `xattr -cr /Applications/TakeCareDev.app` (или правый клик → «Открыть»).
- **Linux:** лучше `.deb` — он ставит AppArmor-профиль, без которого Electron на Ubuntu 24.04+
  работает только с `--no-sandbox` (AppImage добавляет этот флаг сам).
  `sudo apt install ./TakeCareDev-0.1.0-linux-amd64.deb`. AppImage нужен `chmod +x`, а на Ubuntu
  24.04 ещё `sudo apt install libfuse2t64`.

## Зачем это

Программист сидит 8–12 часов в день и смотрит в экран в полуметре от лица. От этого тихо ломаются
две вещи: глаза и всё, что ниже пояса.

### Падающее зрение

- **Близорукость — эпидемия.** В 2020 году близоруким был примерно каждый третий человек на Земле;
  прогноз на 2050 год — около половины, почти 5 миллиардов. Долгая работа вблизи и мало времени,
  когда взгляд направлен вдаль, — среди главных факторов риска.
- **Спазм аккомодации.** Чтобы держать фокус на 50 см, цилиарная мышца часами остаётся
  напряжённой. После долгого дня всё вдали плывёт, глаза ноют, болит голова — «компьютерный
  зрительный синдром».
- **Сухой глаз.** Глядя в экран, мы моргаем в 3–4 раза реже обычного (примерно 15–20 раз в минуту
  падает до ~5). Слёзная плёнка высыхает: жжение, покраснение, песок в глазах.
- **Что помогает:** правило 20-20-20, которое рекомендуют офтальмологи, — каждые 20 минут на
  20 секунд смотреть на что-то в ~6 метрах (20 футах), — плюс осознанное моргание и смена фокуса.
  Ровно это лицо и делает.

Честно: гимнастика не вылечит уже имеющуюся близорукость. Она снимает напряжение и сухость и
поддерживает привычку отводить взгляд — то, что в твоих руках.

### Геморрой и сидение

- **Давление.** Когда сидишь, вены анального канала под постоянным давлением, а отток крови из
  малого таза замедляется. Вены растягиваются, «подушки» сползают вниз — это и есть геморрой.
- **Неподвижный кишечник.** Мало движения — медленнее перистальтика, запоры и натуживание, главный
  триггер геморроя. Туда же — долгое сидение в туалете с телефоном.
- **Это очень частая штука.** По разным исследованиям, геморрой есть у ~4–40% взрослых в
  зависимости от методики; просто об этом молчат, пока не заболит.
- **Что помогает:** вставать каждые 45–60 минут и ходить несколько минут. Ходьба восстанавливает
  венозный отток и запускает кишечник. Приседания и лестница из подсказок перерыва — ещё лучше.

Долгое сидение ещё связано с болью в спине и шее, плохим кровообращением в ногах и повышенным
сердечно-сосудистым риском, так что перерыв на прогулку окупается многократно.

TakeCareDev не заменяет врача. Если уже болит или зрение упало — к офтальмологу / проктологу.

## Структура проекта

```
src/
  main/            main-процесс Electron
    main.js        точка входа: связка модулей, меню трея, IPC, перезапуск Wayland → XWayland
    scheduler.js   чистая логика таймеров (без Electron), покрыта тестами
    face.js        прозрачное окно с лицом у курсора, пропускает клики
    break.js       экран(ы) перерыва, строгий режим на всех мониторах
    cursor.js      отслеживание курсора под разные платформы и сессии
    idle.js        время простоя (powerMonitor или Mutter по D-Bus на GNOME Wayland)
    store.js       настройки и статистика за день в JSON
    tray.js        иконка и меню в трее
    autostart.js   автозапуск (.desktop на Linux, login items на остальных)
    icons.js       иконки трея и приложения из спрайта (raster.js → PNG)
    settings-window.js, json-file.js
  preload/
    preload.cjs    отдаёт окнам window.tcdev (face, breakScreen, settings)
  renderer/        окна: лицо, перерыв, настройки (чистые HTML/CSS/JS, без фреймворков)
  shared/
    sprite.js      спрайт лица, рисуется кодом — картинок нет
    exercises.js   упражнения: что лицо делает в каждую секунду
    i18n.js        переводы (ru, en)
    settings.js    схема настроек и значения по умолчанию
build/             иконки приложения
scripts/
  make-icons.js    рисует build/icon.png из спрайта
  adhoc-sign.js    ad-hoc подпись macOS-сборок, собранных не на macOS (rcodesign)
test/              тесты планировщика на node:test
```

### Сборка

```bash
npm install
npm run dist:linux   # dist/*.AppImage, dist/*.deb
npm run dist:win     # dist/*.exe (установщик и portable)
npm run dist:mac     # dist/*.dmg, dist/*.zip (arm64 и x64)
```

Остальные платформы с Linux:

```bash
npx electron-builder --win portable           # portable .exe; установщик NSIS требует wine
npx electron-builder --mac zip --x64 --arm64  # DMG собирается только на macOS
```

Для macOS вне macOS нужен [rcodesign](https://github.com/indygreg/apple-platform-rs/releases) в
`PATH` (или `RCODESIGN=/путь`): без ad-hoc подписи Apple Silicon приложение не запустит.

### Разработка

```bash
npm start                              # electron . --no-sandbox
npm test                               # логика таймеров и настроек
npm run icons                          # пересобрать build/icon.png из спрайта
TCDEV_DATA_DIR=/tmp/tc npm start       # отдельный профиль настроек
```

### Linux и Wayland

- Wayland не даёт приложениям видеть курсор и ставить окна по координатам, поэтому в
  Wayland-сессии приложение перезапускается через XWayland (`--ozone-platform=x11`). XWayland
  узнаёт позицию курсора, только когда тот над его окном, поэтому перед показом лица на долю
  секунды показывается прозрачное окно на каждом мониторе. Следовать за курсором на Wayland лицо
  не может — только появиться рядом.
- Время простоя на GNOME берётся у Mutter (`org.gnome.Mutter.IdleMonitor` по D-Bus): штатный
  `powerMonitor` Electron под Wayland всегда возвращает 0. На других Wayland-композиторах функции,
  завязанные на простой, отключаются.
- Иконке в трее на GNOME нужно расширение AppIndicator (в Ubuntu включено по умолчанию). Без него
  настройки открываются повторным запуском приложения.
