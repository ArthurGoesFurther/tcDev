# Разминка

Пиксельное лицо напоминает делать гимнастику для глаз и вставать походить. Linux, Windows, macOS.

![icon](build/icon.png)

## Что умеет

- **Глаза.** Каждые N минут (по умолчанию 20, правило 20-20-20) рядом с курсором появляется
  пиксельное лицо и N секунд (по умолчанию 10) показывает упражнение: влево-вправо, вверх-вниз,
  круги, диагонали, восьмёрка, моргание, зажмуриться, вдаль, близко-далеко, отдых с закрытыми
  глазами. Окно прозрачное, пропускает клики и не забирает фокус. Можно выбрать упражнения,
  порядок, размер лица, угол экрана вместо курсора, подсказку и звук.
- **Встать и походить.** Каждые N минут (по умолчанию 50) — перерыв на N минут (по умолчанию 5):
  карточка с таймером, «Отложить» и «Пропустить». Строгий режим закрывает все мониторы и прячет
  кнопки (экстренный выход — меню в трее).
- Таймер перерыва по умолчанию идёт только пока ты не трогаешь мышь и клавиатуру.
- Уведомление за N секунд до перерыва.
- Если тебя нет за компьютером дольше N минут (или ноутбук спал), отсчёт начинается заново.
- Пауза на 30 мин / 1 ч / 2 ч / до возобновления, статистика за день, автозапуск, русский и
  английский.

Все интервалы и длительности задаются в настройках (трей → «Настройки…» или повторный запуск
приложения).

## Сборка и установка

```bash
npm install
npm run dist:linux   # dist/*.AppImage, dist/*.deb
npm run dist:win     # dist/*.exe (установщик и portable)
npm run dist:mac     # dist/*.dmg, dist/*.zip (arm64 и x64)
```

Под все три ОС сразу собирает `.github/workflows/build.yml` (по тегу `v*` или вручную) — если
репозиторий зеркалирован на GitHub.

С Linux можно собрать и остальное:

```bash
npx electron-builder --win portable    # dist/*-win-portable.exe; установщик NSIS требует wine
npx electron-builder --mac zip --x64 --arm64   # DMG собирается только на macOS
```

Для macOS вне macOS нужен [rcodesign](https://github.com/indygreg/apple-platform-rs/releases)
в `PATH` (или `RCODESIGN=/путь`): `scripts/adhoc-sign.js` ставит ad-hoc подпись, без неё Apple
Silicon приложение не запустит.

- **Linux:** лучше `.deb` — он ставит AppArmor-профиль, без которого Electron на Ubuntu 24.04+
  работает только с `--no-sandbox` (AppImage добавляет этот флаг сам). AppImage на Ubuntu 24.04
  требует `sudo apt install libfuse2t64`.
- **Windows:** сборка без подписи, SmartScreen попросит «Подробнее → Выполнить в любом случае».
- **macOS:** ad-hoc подпись без нотаризации, первый запуск — правый клик → «Открыть» или
  `xattr -cr /Applications/Razminka.app`.

## Разработка

```bash
npm start                              # electron . --no-sandbox
npm test                               # логика таймеров и настроек
npm run icons                          # пересобрать build/icon.png из спрайта
RAZMINKA_DATA_DIR=/tmp/rz npm start    # отдельный профиль настроек
```

- `src/main` — main-процесс; `scheduler.js` — чистая логика таймеров без Electron.
- `src/renderer` — окна: лицо, перерыв, настройки.
- `src/shared` — спрайт (рисуется кодом, картинок нет), упражнения, переводы, схема настроек.

## Linux и Wayland

- Wayland не даёт приложениям видеть курсор и ставить окна по координатам, поэтому в
  Wayland-сессии приложение перезапускается через XWayland (`--ozone-platform=x11`). XWayland
  узнаёт позицию курсора, только когда тот оказывается над его окном, поэтому перед показом
  лица на долю секунды показывается прозрачное окно на каждом мониторе. Следовать за курсором
  на Wayland лицо не может — только появиться рядом.
- Время простоя на GNOME берётся у Mutter (`org.gnome.Mutter.IdleMonitor` по D-Bus): штатный
  `powerMonitor` Electron под Wayland всегда возвращает 0. На других Wayland-композиторах
  функции, завязанные на простой, отключаются.
- Иконке в трее на GNOME нужно расширение AppIndicator (в Ubuntu включено по умолчанию). Без
  него настройки открываются повторным запуском приложения.
